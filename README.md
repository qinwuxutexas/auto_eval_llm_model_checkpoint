# Auto Eval LLM Model Checkpoint Selection

Installable Python package for **automated multimodal LLM checkpoint selection**
(Stage I pointwise → Stage II listwise → Stage III pairwise + bootstrap stability).

Hugging Face mirror of the original assets:
[vlmgrounding/AgenticCheckpointEval](https://huggingface.co/datasets/vlmgrounding/AgenticCheckpointEval/)

## Layout

```
src/agentic_eval/          # installable package
  judges/                  # JudgeClient ABC, Mock, OpenAI
  pointwise.py / listwise.py / pairwise.py
  pipeline.py / stability.py / metrics.py / quality.py
  cli.py                   # python -m agentic_eval ...
scripts/                   # thin entry wrappers + reproducibility check
configs/                   # default.yaml, mock.yaml
data/
  images/                  # 100 eval images
  samples/mock_mini.jsonl  # tiny fixture for smoke / CI
results/
  mock_smoke/              # regenerated by scripts/verify_reproducibility.py
  mock_test/               # historical dry-run from another machine (reference)
  experiment_1-Qwen_2.5VL/ # paper figures (need original GPU JSONL to regenerate)
notebooks/                 # archived Colab monoliths (not the source of truth)
```

## Install

```bash
pip install -e .
# optional API / PDF helpers
pip install -e ".[all]"
```

## Reproducible smoke run (no API / no GPU)

```bash
python -m agentic_eval evaluate \
  --data data/samples/mock_mini.jsonl \
  --config configs/mock.yaml \
  --out-dir results/mock_smoke \
  --mock

python scripts/verify_reproducibility.py
pytest -q
```

Same seed + same JSONL + `MockJudgeClient` → identical CSVs/JSON every time.
Each run also writes `config.json` next to the stage outputs.

## Real judge evaluation

1. Put your evaluation JSONL next to the images (schema below).
2. Export `OPENAI_API_KEY` (or implement a custom `JudgeClient` for Gemini/Claude).
3. Run:

```bash
python -m agentic_eval evaluate \
  --data path/to/eval.jsonl \
  --config configs/default.yaml \
  --out-dir results/experiments/my_run \
  --openai \
  --image-root .
```

### JSONL schema

Each line:

```json
{
  "sample_id": "sample_0001",
  "image_path": "data/images/ckpt_1.png",
  "question": "...",
  "responses": {
    "ckpt_2000": "...",
    "ckpt_4000": "..."
  }
}
```

## Reproducing paper figures (`experiment_1-Qwen_2.5VL`)

Checked-in artifacts under `results/experiment_1-Qwen_2.5VL/` and `demo/` are
**figures from a GPU machine run**. That machine used a slightly different
checkout (judge wiring / prompts). To regenerate those numbers bit-for-bit you need:

1. The original evaluation JSONL (checkpoint responses for the 100 images) from that run
2. The same judge model IDs + temperatures recorded in that run’s `config.json`
3. This package’s Stage I–III pipeline (`python -m agentic_eval evaluate ...`)

If you still have the GPU workspace, copy its eval JSONL into `data/samples/` and
point `--config` at the saved config from that run.

`results/mock_test/` is a historical mock snapshot and may differ slightly from
`results/mock_smoke/` generated by the current packaged `MockJudgeClient`.
